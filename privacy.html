Privacy Policy

TrendingTVBackdrops does not collect, store or share any personal data about Reddit users.

  • It does not read users' posts, comments or messages.
  • It does not use cookies, analytics or tracking.
  • It stores only technical state (which images it has already posted and the ids of its own posts) so it can delete last week's posts.
  • It only reads one public file (a list of image links) from this website.

Questions: send a message to the moderators of r/WeeklyTVBackdrops (modmail).
